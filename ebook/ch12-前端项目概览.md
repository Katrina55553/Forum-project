# 第十二章：前端项目概览 — 入口与架构

## 技术栈

| 技术 | 用途 |
|------|------|
| **Vue 3** | 前端框架（Composition API + `<script setup>`） |
| **Pinia** | 状态管理（全站只有一个 `auth` store） |
| **Vue Router 4** | 前端路由（12 条，全部懒加载） |
| **Axios** | HTTP 客户端 |
| **marked** | Markdown → HTML |
| **DOMPurify** | 清洗 Markdown 渲染出的 HTML，防止 XSS |
| **Vite** | 构建工具 + 开发服务器 |

比起最小可用的 Vue 应用，这里多了两样"内容型产品"必备的东西：Markdown 渲染、以及把渲染结果洗干净 —— 凡是把用户输入 `v-html` 到页面的地方，都要先过一遍 `DOMPurify.sanitize()`。

> **两处曾经存在的认知陷阱（均已于 2026-09-26 修复），读这份教程前先知道**：
>
> **一、`highlight.js` 的接线方式随 `marked` 版本变了。** `marked` 从 **v5 起删掉了 `setOptions({ highlight })` 选项**（改成独立的 `marked-highlight` 插件），旧写法会被**静默忽略**。现在 `TopicDetailView.vue` 用 `marked.use({ renderer: { code({text, lang}) } })` 自定义代码块渲染器，在里面直接调 `hljs.highlight()` / `hljs.highlightAuto()`，输出带 `hljs language-*` class 的 `<pre><code>`。顺带一提，`TopicEditView` 压根没导入 `hljs`，它的实时预览从来就没有高亮（历史行为，未改）。
>
> **二、三个 `@bytemd/*` 包曾经是纯残留。** `package.json` 里曾声明着 `@bytemd/vue-next`、`@bytemd/plugin-gfm`、`@bytemd/plugin-highlight`，但整个 `src/` 一次都没引用——ByteMD 是这套代码还是博客时用的编辑器，论坛改造时换成了 textarea + `marked`，依赖却没跟着删掉。已于 2026-09-26 从 `package.json` 移除（连带卸载 115 个包）。

## 应用入口 — main.js

```javascript
import { createApp } from "vue";
import { createPinia } from "pinia";
import App from "./App.vue";
import router from "./router";
import "./style.css";

const app = createApp(App);
app.use(createPinia());
app.use(router);
app.mount("#app");
```

流程非常线性：创建应用 → 注册 Pinia → 注册 Router → 挂载。这里还要注意 `import "./style.css"`——全局主题变量就定义在这个文件里，它必须在挂载前被引入。

## 根组件 — App.vue

App.vue 是整个应用的骨架，负责导航布局、主题初始化、未读轮询，以及挂载三个全局组件。

### 导航栏

```
┌────────────────────────────────────────────────────────────┐
│  ✦ Inkwell   首页  发帖    [✉ 3]  [头像▾]  [主题]  [GitHub] │ ← 固定顶部
└────────────────────────────────────────────────────────────┘
│                     <router-view />                        │ ← 页面内容区
```

导航栏分左右两组：

- **左侧**：带 `✦` 标记的品牌 Logo（`Inkwell`）、首页链接、登录后出现的发帖入口（CTA 胶囊按钮）
- **右侧**：消息入口、用户头像下拉菜单、主题切换按钮、GitHub 外链

和旧版不同，导航栏里**没有搜索框**（搜索移到了 HomeView 页面内），消息入口也**不是 emoji 铃铛**，而是一个 SVG 对话气泡图标：

```html
<router-link v-if="auth.user" to="/messages" class="nav-icon-btn nav-messages" aria-label="消息">
  <svg width="18" height="18" viewBox="0 0 24 24" ...>...</svg>
  <span v-if="totalUnread > 0" class="notif-badge">{{ totalUnread > 99 ? '99+' : totalUnread }}</span>
</router-link>
```

角标显示的是**未读通知 + 未读私信之和**，超过 99 显示 `99+`：

```javascript
const unreadCount = ref(0);
const unreadMessageCount = ref(0);
const totalUnread = computed(() => unreadCount.value + unreadMessageCount.value);
```

登录后头像位置出现下拉菜单，含「编辑信息」和「退出账号」，并展示当前用户名与角色（管理员 / 成员）。未登录时右侧只有「登录 / 注册」。

### 主题初始化

主题由 `data-theme` 属性驱动：亮色时移除该属性，暗色时设为 `"dark"`。初始化时优先读 `localStorage`，其次跟随系统：

```javascript
function initTheme() {
  const saved = localStorage.getItem("theme");
  if (saved === "dark" || (!saved && window.matchMedia("(prefers-color-scheme: dark)").matches)) {
    isDark.value = true;
    document.documentElement.setAttribute("data-theme", "dark");
  }
}

function toggleTheme() {
  isDark.value = !isDark.value;
  document.documentElement.setAttribute("data-theme", isDark.value ? "dark" : "");
  localStorage.setItem("theme", isDark.value ? "dark" : "light");
}
```

### 未读轮询：为什么要"启停"而不是"一直跑"

导航栏要显示未读角标，需要定期向后端问一次。做法是每 30 秒轮询一次，但同时拉通知未读数和私信未读数：

```javascript
let notifTimer = null;

function startPolling() {
  if (notifTimer) clearInterval(notifTimer);   // 先清旧的，避免多个定时器叠加
  fetchUnreadCount();
  fetchUnreadMessageCount();
  notifTimer = setInterval(() => {
    fetchUnreadCount();
    fetchUnreadMessageCount();
  }, 30000);
}

function stopPolling() {
  if (notifTimer) {
    clearInterval(notifTimer);
    notifTimer = null;
  }
}
```

关键在于**只在登录状态下轮询**。未登录时请求未读数没有意义，还会打一堆 401。于是用一个 `watch` 监听登录状态的变化，登录则启、退出则停：

```javascript
watch(() => auth.user, (newUser, oldUser) => {
  if (newUser && !oldUser) {
    startPolling();
  } else if (!newUser && oldUser) {
    stopPolling();
  }
});
```

### 生命周期清理（一个真实修过的内存泄漏）

组件挂载时除了启动逻辑，还要登记两个全局监听；卸载时必须**成对地注销**，否则定时器和事件监听会一直留着：

```javascript
function onAuthExpired() {
  auth.clearAuth();       // 让 Pinia 状态清空
  stopPolling();          // token 失效后停止轮询
}

onMounted(async () => {
  initTheme();
  await auth.restoreUser();                                  // 用本地 token 恢复登录
  document.addEventListener("click", onDocClick);            // 点击空白关闭菜单
  window.addEventListener("auth-expired", onAuthExpired);    // 监听 401 过期事件
  if (auth.user) {
    startPolling();
  }
});

onBeforeUnmount(() => {
  document.removeEventListener("click", onDocClick);
  window.removeEventListener("auth-expired", onAuthExpired);
  if (notifTimer) clearInterval(notifTimer);
});
```

`auth-expired` 是响应拦截器在 token 失效时派发的自定义事件（见 API 层），App.vue 收到后同步清空 Pinia 并停掉轮询——这样"拦截器硬跳登录页"和"内存里的登录状态"就保持一致了。

## 主题系统 — style.css

旧版教程把主题写成蓝色系（`#3b82f6`），**这是错的**。当前设计的是一套「暖纸 / 深墨」双色板，`:root` 定义约 60 条 CSS 变量。亮色叫**暖纸**，暗色叫**深墨**：

```css
:root {
  /* Warm paper palette — light mode */
  --color-bg: #f7f3ec;            /* 暖纸底 */
  --color-bg-elevated: #fffdf8;   /* 抬升面（卡片、弹窗） */
  --color-text: #1c1a17;
  --color-primary: #b8431f;       /* 砖红主色 */
  --color-primary-hover: #9c371a;
  --color-accent: #2d5a3d;        /* 墨绿点缀 */
}

[data-theme="dark"] {
  /* Deep ink palette — dark mode */
  --color-bg: #161310;
  --color-text: #ece4d6;
  --color-primary: #e07a4c;       /* 暗色下的主色要提亮 */
}
```

除了颜色，还定义了字体、圆角、阴影等设计令牌：

```css
--font-display: "Fraunces", "Songti SC", "Noto Serif SC", Georgia, serif;   /* 标题用衬线 */
--font-sans: "Manrope", -apple-system, BlinkMacSystemFont, ... sans-serif;  /* 正文 */
--font-mono: "JetBrains Mono", "Fira Code", "Cascadia Code", Consolas, monospace;
--radius-sm: 4px;
--radius: 8px;
--radius-lg: 14px;
--radius-xl: 22px;
```

三款字体（Fraunces / Manrope / JetBrains Mono）通过 `style.css` 顶部的 `@import` 从 Google Fonts 引入。页面里所有颜色、圆角、字号都引用变量而非裸值，这也是切换主题只需改一个 `data-theme` 就能全局生效的原因。

## 响应式设计

导航栏在 **≤640px** 视口时折叠为汉堡菜单：`.hamburger` 由 `display: none` 变为 `display: flex`，`nav` 从横向排列变成竖向展开的下拉面板，通过 `nav.open` 类控制显隐：

```html
<button class="hamburger" @click="menuOpen = !menuOpen"
        :aria-label="menuOpen ? '关闭菜单' : '打开菜单'">
  <span></span><span></span><span></span>   <!-- 三条横线 -->
</button>
<nav ref="navRef" :class="{ open: menuOpen }">
  <!-- 导航链接 -->
</nav>
```

`onDocClick` 会在点击导航栏外部时自动收起菜单，避免用户"点空白处关不掉"的困扰。

## 本章要点

- 入口流程：createApp → Pinia → Router → mount，别忘 `import "./style.css"`
- App.vue 是应用骨架：导航布局 + 主题 + 未读轮询 + 全局组件挂载
- 未读轮询要跟随登录状态**启停**，并在 `onBeforeUnmount` 清理定时器与事件监听
- 主题是一套「暖纸 / 深墨」双色板，靠 CSS 变量 + `data-theme` 切换
- `NotificationsView.vue` 曾是无人引用的死代码（2026-09-26 已删），读源码要习惯先用 grep 确认引用关系
