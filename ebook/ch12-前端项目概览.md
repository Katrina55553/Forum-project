# 第十二章：前端项目概览 — 入口与架构

## 技术栈

| 技术 | 用途 |
|------|------|
| **Vue 3** | 前端框架（Composition API + `<script setup>`） |
| **Pinia** | 状态管理 |
| **Vue Router 4** | 前端路由 |
| **Axios** | HTTP 客户端 |
| **Vite** | 构建工具 + 开发服务器 |

## 3.1 应用入口 — main.js

```javascript
import { createApp } from "vue";
import { createPinia } from "pinia";
import App from "./App.vue";
import router from "./router";

const app = createApp(App);
app.use(createPinia());
app.use(router);
app.mount("#app");
```

非常简洁：创建 Vue 应用 → 注册 Pinia → 注册 Router → 挂载。

## 3.2 根组件 — App.vue

App.vue 是整个应用的骨架，分三部分：

### 导航栏

```
┌─────────────────────────────────────────────────┐
│  Logo  首页  发帖  │  搜索  🔔(3)  👤  🌙  GitHub │  ← 固定顶部
└─────────────────────────────────────────────────┘
│                    │
│   <router-view />  │  ← 页面内容区域
│                    │
```

导航栏包含：
- **左侧**：Logo、首页链接、发帖链接
- **右侧**：通知铃铛（带未读计数徽章）、用户头像下拉菜单、主题切换、GitHub 链接

### 通知轮询

```javascript
// App.vue 每隔 30 秒轮询未读通知数
onMounted(() => {
  fetchUnreadCount();
  setInterval(fetchUnreadCount, 30000);
});
```

### 全局组件挂载

```html
<BackToTop />
<AppToast />
<ConfirmDialog />
```

这三个全局组件在整个应用任何地方都可以用，但只在 App.vue 里挂载一次。

## 3.3 主题系统 — style.css

```css
:root {
  --color-bg: #ffffff;
  --color-text: #1a1a2e;
  --color-primary: #3b82f6;
  /* ... 更多变量 */
}

[data-theme="dark"] {
  --color-bg: #0f172a;
  --color-text: #e2e8f0;
  --color-primary: #60a5fa;
}
```

- 定义了 **26 个 CSS 自定义属性**（颜色、阴影、字体、间距等）
- 通过切换 `[data-theme="dark"]` 实现明暗主题
- 偏好持久化到 `localStorage`
- 首次访问自动检测 `prefers-color-scheme`

```javascript
// 主题切换逻辑
function toggleTheme() {
  const newTheme = theme.value === "dark" ? "light" : "dark";
  theme.value = newTheme;
  document.documentElement.setAttribute("data-theme", newTheme);
  localStorage.setItem("theme", newTheme);
}
```

## 3.4 响应式设计

导航栏在 **≤640px** 视口时折叠为汉堡菜单：

```html
<button class="hamburger" @click="menuOpen = !menuOpen">
  <span></span><span></span><span></span>   <!-- 三条横线 -->
</button>
<nav :class="{ open: menuOpen }" @click.self="menuOpen = false">
  <!-- 导航链接 -->
</nav>
```

## 本章要点

- Vue 3 应用的典型入口流程：createApp → Pinia → Router → mount
- App.vue 是应用的骨架，负责导航布局和全局组件挂载
- CSS 变量是实现主题切换的最轻量方案
- 组件、composable、API 层各司其职，职责分离
