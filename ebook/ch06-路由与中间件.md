main.py 是整个后端的**大脑**——串联所有模块，处理每一个 HTTP 请求。约 260 行代码。

## 中间件

中间件像过滤管道——每个请求和响应都会经过它们。

### CORS 中间件

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=[os.environ.get("CORS_ORIGIN", "http://localhost:5173")],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

**CORS 是什么？** 浏览器同源策略：A 网站的 JS 不能访问 B 网站的数据。前端在 `localhost:5173`，后端在 `localhost:8000`，端口不同 → 不同源 → 浏览器拦截。CORS 中间件在响应头加 `Access-Control-Allow-Origin` 来放行。

### 请求日志

```python
@app.middleware("http")
async def log_requests(request, call_next):
    start = time.time()
    response = await call_next(request)
    duration = time.time() - start
    logger.info(f"{request.method} {request.url.path} {response.status_code} ({duration:.3f}s)")
    return response
```

记录示例：`GET /api/topics 200 (0.032s)`

## 统一错误处理

```python
@app.exception_handler(404)
async def not_found_handler(request, exc):
    return JSONResponse(status_code=404, content={"detail": "Not found"})

@app.exception_handler(RateLimitExceeded)
async def rate_limit_handler(request, exc):
    return JSONResponse(status_code=429, content={"detail": "Too many requests"})

@app.exception_handler(Exception)
async def unhandled_exception_handler(request, exc):
    logger.error(f"Unhandled: {exc}\n{traceback.format_exc()}")
    return JSONResponse(status_code=500, content={"detail": "Internal server error"})
```

客户端收到的永远是 `{"detail": "..."}` 格式。

## HTML 过滤（防 XSS）

```python
ALLOWED_TAGS = ["b", "i", "em", "strong", "a", "p", "br", "ul", "ol", "li",
                "pre", "code", "h1", "h2", "h3", "blockquote", "img", ...]

def sanitize(text: str) -> str:
    return bleach.clean(text, tags=ALLOWED_TAGS, attributes=ALLOWED_ATTRS, strip=True)
```

用户输入可能包含 `<script>alert('xss')</script>`，bleach 只保留白名单中的安全标签。

## 权限检查

```python
def _author_or_admin(topic: Topic, user: User):
    if topic.author_id != user.id and not user.is_admin:
        raise HTTPException(status_code=403, detail="Not your topic")

def _comment_author_or_admin(comment: Comment, user: User):
    if comment.user_id != user.id and not user.is_admin:
        raise HTTPException(status_code=403, detail="Not your comment")
```

## 路由详解

### 认证路由

```python
@app.post("/api/auth/register", response_model=UserResponse, status_code=201)
@limiter.limit("5/minute")
def register(request, data: UserRegister, db: Session = Depends(get_db)):
    if get_user_by_username(db, data.username):
        raise HTTPException(status_code=409, detail="Username already exists")
    return create_user(db, data.username, data.password)

@app.post("/api/auth/login", response_model=TokenResponse)
@limiter.limit("10/minute")
def login(request, data: UserLogin, db: Session = Depends(get_db)):
    user = get_user_by_username(db, data.username)
    if not user or not verify_password(data.password, user.password_hash):
        raise HTTPException(status_code=401, detail="Invalid credentials")
    token = create_access_token({"sub": str(user.id)})
    return TokenResponse(access_token=token)
```

`if not user or not verify_password(...)` — 无论是"用户不存在"还是"密码错误"，都返回同样的 401，防止攻击者试探用户名。

### 帖子路由

```python
# 列表（公开）
@app.get("/api/topics")
def list_topics(page: int = 1, size: int = 10, q: str = "", db = Depends(get_db)):
    items, total = get_topics(db, page=page, size=size, q=q)
    return {"items": items, "total": total, "page": page, "size": size,
            "pages": (total + size - 1) // size if total > 0 else 0}

# 详情（公开 + 可选登录）
@app.get("/api/topics/{topic_id}", response_model=TopicDetailResponse)
def detail_topic(topic_id, db = Depends(get_db),
                 current_user = Depends(get_optional_user)):
    topic = get_topic_by_id(db, topic_id)
    if not topic:
        raise HTTPException(404)
    increment_view_count(db, topic)   # +1 浏览量
    is_liked = any(u.id == current_user.id for u in topic.likes) if current_user else False
    return {..., "is_liked": is_liked, "comments": build_comment_tree(topic.comments)}
```
