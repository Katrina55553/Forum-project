# 第十章：前端如何调用 API

## 完整调用链路

```
浏览器
  └─ Vue 组件（HomeView.vue）
       └─ API 函数（api/topic.js）
            └─ Axios 客户端（api/client.js）
                 └─ HTTP → localhost:5173/api/...
                      └─ Vite 代理转发 → localhost:8000/api/...
                           └─ FastAPI 后端 → PostgreSQL
```

## Axios 客户端（api/client.js）

```javascript
import axios from "axios";

const client = axios.create({
  baseURL: "/api",       // 自动加 /api 前缀
  timeout: 10000,
});

// 请求拦截器：自动带 JWT token
client.interceptors.request.use((config) => {
  const token = localStorage.getItem("token");
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截器：401 自动跳登录
client.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem("token");
      localStorage.removeItem("user");
      window.location.href = `/login?redirect=${encodeURIComponent(window.location.pathname)}`;
    }
    return Promise.reject(error);
  }
);
```

### 自动带 token

从 localStorage 取出之前登录存的 JWT，自动加到 `Authorization` 请求头。所有 API 函数都不用自己处理 token。

### 401 自动跳登录

后端返回 401（token 过期或无效）→ 清除本地状态 → 跳登录页。还带了 `?redirect=` 参数，登录成功后再跳回来。

## API 函数封装

```javascript
// api/topic.js
export function getTopics(page = 1, size = 10, q = "") {
  return client.get("/topics", { params: { page, size, q } });
}
export function getTopicById(id) { return client.get(`/topics/${id}`); }
export function createTopic(data) { return client.post("/topics", data); }
export function updateTopic(id, data) { return client.put(`/topics/${id}`, data); }
export function deleteTopic(id) { return client.delete(`/topics/${id}`); }

// api/auth.js
export function login(username, password) {
  return client.post("/auth/login", { username, password });
}
export function getMe() { return client.get("/auth/me"); }

// api/comment.js
export function createComment(topicId, content, parentId = null) {
  return client.post("/comments", { content, topic_id: topicId, parent_id: parentId });
}

// api/like.js
export function likeTopic(topicId) { return client.post(`/likes/${topicId}`); }
export function unlikeTopic(topicId) { return client.delete(`/likes/${topicId}`); }

// api/notification.js
export function getUnreadCount() { return client.get("/notifications/unread-count"); }
export function markAllRead() { return client.put("/notifications/read-all"); }
```

路径不写 `/api` 前缀，因为 `client.js` 的 `baseURL` 已经加了。

## 视图层 — 三种状态

```javascript
// 状态变量
const topics = ref([]);       // 数据
const loading = ref(true);    // 加载中
const error = ref("");        // 错误信息

// 请求函数
async function fetchTopics() {
  loading.value = true;
  error.value = "";
  try {
    const res = await getTopics(page.value, size, q.value);
    topics.value = res.data.items;
    pages.value = res.data.pages;
  } catch {
    error.value = "加载失败，请稍后重试";
  } finally {
    loading.value = false;
  }
}

onMounted(fetchTopics);
watch(page, fetchTopics);
```

```html
<!-- 加载中：骨架屏 -->
<div v-if="loading" class="skeleton-list">...</div>

<!-- 错误：提示 + 重试 -->
<div v-else-if="error">
  <p>{{ error }}</p>
  <button @click="fetchTopics">重试</button>
</div>

<!-- 空数据 -->
<div v-else-if="topics.length === 0">暂无帖子</div>

<!-- 正常渲染 -->
<div v-else>
  <div v-for="t in topics" :key="t.id">
    <router-link :to="`/topic/${t.id}`">{{ t.title }}</router-link>
  </div>
</div>
```

## 完整示例：用户登录

```
用户点击登录
  → auth store: login(username, password)
    → api/auth.js: login(username, password)
      → client.post("/auth/login", {username, password})
        → Vite 代理转发到 :8000
          → 后端验证密码，生成 JWT
        ← 返回 {"access_token": "eyJ...", "token_type": "bearer"}
    ← 拿到 token
    → localStorage.setItem("token", token)
    → restoreUser()
      → client.get("/auth/me")  带着 token
        → 后端解码 JWT，查数据库
      ← 返回 {id:1, username:"admin", is_admin:true}
  ← 登录完成
  → router.push 跳转到首页
```

## Vite 代理（解决跨域）

```javascript
// vite.config.js
export default defineConfig({
  server: {
    proxy: {
      "/api": {
        target: "http://localhost:8000",
        changeOrigin: true,
      },
    },
  },
});
```

工作流程：

```
浏览器请求 /api/topics
       │
       ▼
  Vite 开发服务器 (:5173)
       │
       ├─ 非 /api → 静态资源
       └─ /api → 转发到 :8000
              │
              ▼
         FastAPI 后端
```

前端写 `baseURL: "/api"` 就够，浏览器只和 5173 通信，没有跨域问题。

## 前后端数据格式对应

后端返回格式：
```json
{
  "items": [{...}],   // 数据数组
  "total": 1,          // 总条数
  "page": 1,           // 当前页
  "size": 10,          // 每页条数
  "pages": 1           // 总页数
}
```

前端取值：
- `res.data.items` → 循环渲染列表
- `res.data.total` → "找到 N 个帖子"
- `res.data.pages` → 生成分页按钮
