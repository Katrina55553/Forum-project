# 第七章：测试数据填充 — seed.py

开发时需要一个有数据的数据库才能调试。seed.py 一键创建管理员和示例帖子。

```python
from database import Base, SessionLocal, engine
from models import Topic, User
from auth import hash_password

def seed():
    Base.metadata.create_all(bind=engine)
    db = SessionLocal()

    # 幂等：admin 已存在就跳过
    admin = db.query(User).filter_by(username="admin").first()
    if not admin:
        admin = User(username="admin", password_hash=hash_password("admin123"), is_admin=True)
        db.add(admin)
        db.flush()     # flush 让数据库生成 id

    # 幂等：已有帖子就跳过
    existing = db.query(Topic).first()
    if not existing:
        topic = Topic(
            title="欢迎来到论坛",
            content="这是第一个帖子！\n\n## 论坛规则\n\n- 请保持友善和尊重\n- 支持 Markdown 格式",
            author_id=admin.id,
        )
        db.add(topic)
        db.commit()
        print("Seed data inserted: admin user + 1 topic")
    else:
        print("Seed data already exists, skipping")

    db.close()


if __name__ == "__main__":
    seed()
```

## 幂等性

多次运行结果一致：

```
第一次 → Seed data inserted: admin user + 1 topic
第二次 → Seed data already exists, skipping
```

两个检查保证幂等：`if not admin` 和 `if not existing`。

## db.flush() vs db.commit()

| 方法 | 写入数据库？ | 事务提交？ | 能拿自增 id？ |
|------|:--------:|:--------:|:-----------:|
| `add()` | 否（缓存） | 否 | 否 |
| `flush()` | 是（发 SQL） | 否（可回滚） | **是** |
| `commit()` | 是 | 是 | 是 |

用 flush 只是为了拿到 admin 的 id 给帖子用，但两个操作还在同一个事务里。

## 使用

```bash
cd backend
python seed.py
# → Seed data inserted: admin user + 1 topic
```
