# 第二章：数据库设计 — models.py

## 2.1 数据库连接（database.py）

```python
import os
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, sessionmaker, DeclarativeBase

DATABASE_URL = os.environ.get("DATABASE_URL", "postgresql://blog:blog@localhost:5432/blog")
engine = create_engine(DATABASE_URL)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)


class Base(DeclarativeBase):
    pass


def get_db():
    """FastAPI 依赖注入：自动获取和关闭数据库连接"""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

### 关键概念

- **create_engine** — 创建数据库连接池，管理复用连接
- **SessionLocal** — 会话工厂，每次请求创建一个 Session（工作单元）
- **DeclarativeBase** — 所有模型类的基类，ORM 通过它发现表定义
- **get_db()** — 生成器函数，FastAPI 用它做依赖注入，请求开始获取 Session、请求结束自动关闭

## 2.2 五张表设计

| 表名 | 用途 | 核心字段 |
|------|------|---------|
| **users** | 用户账号信息 | username, password_hash, avatar, is_admin |
| **topics** | 帖子/话题 | title, content, author_id, view_count |
| **comments** | 评论与回复 | content, topic_id, user_id, parent_id |
| **likes** | 用户点赞关系 | user_id + topic_id（联合主键） |
| **notifications** | 消息通知 | user_id, type, topic_id, is_read |

## 2.3 User 模型

```python
class User(Base):
    __tablename__ = "users"

    id = Column(Integer, primary_key=True, index=True)
    username = Column(String, unique=True, nullable=False, index=True)
    password_hash = Column(String, nullable=False)
    avatar = Column(String, default="")
    bio = Column(String, default="")
    github_url = Column(String, default="")
    is_admin = Column(Boolean, default=False)
    topic_count = Column(Integer, default=0)
    comment_count = Column(Integer, default=0)
    created_at = Column(DateTime, default=lambda: datetime.now(timezone.utc))
```

### 字段设计要点

- **主键 id**：自增整数，每行记录的唯一标识
- **unique=True + index=True**：保证用户名唯一，同时加索引加速查找
- **password_hash**：存 bcrypt 加密后的密码，**绝不存明文**
- **topic_count/comment_count**：冗余统计字段，避免每次都要 COUNT 查询（以空间换时间）
- **default=lambda: datetime.now(timezone.utc)**：用 lambda 确保创建记录时才获取时间，而不是模块加载时

## 2.4 Topic 模型

```python
class Topic(Base):
    __tablename__ = "topics"

    id = Column(Integer, primary_key=True, index=True)
    title = Column(String, nullable=False)
    content = Column(Text, default="")
    author_id = Column(Integer, ForeignKey("users.id"), nullable=False)
    view_count = Column(Integer, default=0)
    created_at = Column(DateTime, default=lambda: datetime.now(timezone.utc))
    updated_at = Column(
        DateTime,
        default=lambda: datetime.now(timezone.utc),
        onupdate=lambda: datetime.now(timezone.utc),
    )

    author = relationship("User", back_populates="topics")
    comments = relationship("Comment", back_populates="topic", cascade="all, delete-orphan")
    likes = relationship("User", secondary="likes")
```

### 关键关系

- **author_id** — 外键指向 users.id，表示"谁发的帖"
- **updated_at** — `default` 是创建时时间，`onupdate` 是每次更新自动刷新
- **cascade="all, delete-orphan"** — 删帖时自动删除所有关联评论
- **secondary="likes"** — 多对多关系桥接 likes 中间表

## 2.5 Comment 模型 — 楼中楼实现

```python
class Comment(Base):
    __tablename__ = "comments"

    id = Column(Integer, primary_key=True, index=True)
    content = Column(Text, nullable=False)
    topic_id = Column(Integer, ForeignKey("topics.id"), nullable=False)
    user_id = Column(Integer, ForeignKey("users.id"), nullable=False)
    parent_id = Column(Integer, ForeignKey("comments.id"), nullable=True)  # 自引用
    created_at = Column(DateTime, default=lambda: datetime.now(timezone.utc))

    parent = relationship("Comment", remote_side="Comment.id", back_populates="replies")
    replies = relationship("Comment", back_populates="parent", cascade="all, delete-orphan")
```

### 自引用实现原理

```
评论1（parent_id=NULL）           ← 顶层评论
  ├── 回复1.1（parent_id=评论1）   ← 对评论1的回复
  │   └── 回复1.1.1（parent_id=回复1.1）  ← 嵌套回复
  └── 回复1.2（parent_id=评论1）
评论2（parent_id=NULL）           ← 另一条顶层评论
```

- `parent_id IS NULL` → 顶层评论，直接回复帖子
- `parent_id = 5` → 对 id=5 的评论的回复
- `remote_side="Comment.id"` — 告诉 SQLAlchemy 自引用中"父"的一方是 id

## 2.6 Notification 模型

```python
class Notification(Base):
    __tablename__ = "notifications"

    id = Column(Integer, primary_key=True, index=True)
    user_id = Column(Integer, ForeignKey("users.id"), nullable=False)
    type = Column(String, nullable=False, default="reply")
    topic_id = Column(Integer, ForeignKey("topics.id"), nullable=True)
    comment_id = Column(Integer, ForeignKey("comments.id"), nullable=True)
    is_read = Column(Boolean, default=False)
    created_at = Column(DateTime, default=lambda: datetime.now(timezone.utc))
```

- **type** — 通知类型（"reply"），预留扩展空间
- **topic_id + comment_id** — 记录上下文，点击通知时跳转到对应帖子

## 2.7 likes 中间表

```python
likes = Table(
    "likes",
    Base.metadata,
    Column("user_id", Integer, ForeignKey("users.id"), primary_key=True),
    Column("topic_id", Integer, ForeignKey("topics.id"), primary_key=True),
)
```

- 不定义 ORM 类，只用 Table 对象
- **联合主键**保证：同一个用户不能给同一个帖子点两次赞

## 表关系总结

```
users ──┬── topics（一对多：一个用户有多篇帖子）
        ├── comments（一对多：一个用户有多条评论）
        └── likes（多对多：用户↔帖子）

topics ──┬── comments（一对多：一个帖子有多条评论）
         └── likes（多对多）

comments ── self（自引用：评论可以回复评论）
```

## 本章要点

- ORM 的核心：用 Python 类描述数据库表，用 relationship 描述表间关系
- 三种关系模式：一对多（ForeignKey）、多对多（secondary）、自引用（remote_side）
- 冗余字段：topic_count/comment_count 以空间换时间
- 默认值：用 lambda 延迟求值，避免模块加载时固定时间
