# 第十五章：核心视图详解

本章详解三个核心页面：帖子列表、帖子详情、发帖/编辑。

## 帖子列表 — HomeView.vue

### 三种状态

```javascript
const topics = ref([]);       // 数据
const loading = ref(true);    // 加载中
const error = ref("");        // 错误信息

async function fetchTopics() {
  loading.value = true;
  error.value = "";
  try {
    const res = await getTopics(page.value, size, q.value);
    topics.value = res.data.items;
    pages.value = res.data.pages;
    total.value = res.data.total;
  } catch {
    error.value = "加载失败，请稍后重试";
  } finally {
    loading.value = false;
  }
}

onMounted(fetchTopics);               // 页面加载时自动请求
watch(page, fetchTopics);             // 翻页时重新请求
watch(q, () => { page.value = 1; fetchTopics(); });  // 搜索时重置到第一页
```

### 模板渲染

```html
<!-- 1. 加载中：骨架屏 -->
<div v-if="loading" class="skeleton-list">
  <div v-for="n in 5" :key="n" class="skeleton-row">
    <div class="skeleton-line w-70"></div>
    <div class="skeleton-line w-40"></div>
  </div>
</div>

<!-- 2. 错误：提示 + 重试 -->
<div v-else-if="error" class="state error">
  <p>{{ error }}</p>
  <button @click="fetchTopics">重试</button>
</div>

<!-- 3. 空数据 -->
<div v-else-if="topics.length === 0" class="state">暂无帖子</div>

<!-- 4. 正常渲染 -->
<div v-else class="topic-list">...</div>
```

### 搜索功能

```html
<form @submit.prevent="doSearch">
  <input v-model="searchInput" type="search" placeholder="搜索帖子..." />
</form>
```

```javascript
function doSearch() {
  const val = searchInput.value.trim();
  page.value = 1;
  router.push({ query: val ? { q: val } : {} });  // 更新 URL 参数
}
```

搜索参数同步到 URL 的 `?q=`，刷新页面搜索状态不丢失。

### 相对时间

```javascript
function formatTime(t) {
  if (!t) return "";
  const diff = Date.now() - new Date(t).getTime();
  const mins = Math.floor(diff / 60000);
  if (mins < 1) return "刚刚";
  if (mins < 60) return `${mins}分钟前`;
  const hours = Math.floor(mins / 60);
  if (hours < 24) return `${hours}小时前`;
  return new Date(t).toLocaleDateString();
}
```

### Markdown 渲染

```javascript
import { marked } from "marked";
import hljs from "highlight.js";

// 配置 marked 使用 highlight.js 做代码高亮
marked.setOptions({
  highlight(code, lang) {
    if (lang && hljs.getLanguage(lang)) {
      return hljs.highlight(code, { language: lang }).value;
    }
    return code;
  },
});

const renderedContent = computed(() => marked(topic.value.content));
```

### 点赞功能

```javascript
const isLiked = ref(false);
const likesCount = ref(0);

async function toggleLike() {
  try {
    if (isLiked.value) {
      const res = await unlikeTopic(props.id);
      isLiked.value = false;
      likesCount.value = res.data.likes_count;
    } else {
      const res = await likeTopic(props.id);
      isLiked.value = true;
      likesCount.value = res.data.likes_count;
    }
  } catch {
    // 未登录时后端返回 401，拦截器会自动跳登录页
  }
}
```

**乐观更新**：点击后立即切换状态，不用等后端响应确认。

## 发帖/编辑 — TopicEditView.vue

```javascript
// 判断模式：有 id 是编辑，没有是新建
const isEdit = computed(() => !!route.params.id);

const title = ref("");
const content = ref("");
const submitting = ref(false);

async function submit() {
  submitting.value = true;
  try {
    if (isEdit.value) {
      await updateTopic(route.params.id, { title: title.value, content: content.value });
      showToast.success("帖子已更新");
    } else {
      const res = await createTopic({ title: title.value, content: content.value });
      showToast.success("发布成功");
      router.push(`/topic/${res.data.id}`);
    }
  } catch {
    showToast.error("操作失败");
  } finally {
    submitting.value = false;
  }
}
```

## 本章要点

- 每个视图都处理四种状态：加载中、错误、空数据、正常
- 骨架屏用 CSS animation 实现，无额外依赖
- 搜索状态同步到 URL，刷新不丢失
- 点赞用乐观更新提升交互响应
- 编辑和新建共用同一个组件，通过 `:id` 参数区分
