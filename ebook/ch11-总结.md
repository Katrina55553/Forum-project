# 第十一章：完整开发流程总结

## 后端开发路径

```
Step 1  搭环境      项目结构、虚拟环境、requirements.txt
  │
  ▼
Step 2  数据库      database.py → 连接配置
                   models.py → User, Topic, Comment, likes, Notification
  │
  ▼
Step 3  数据校验    schemas.py → Pydantic 请求/响应模型
  │
  ▼
Step 4  业务逻辑    crud.py → 所有数据库操作函数
  │
  ▼
Step 5  认证系统    auth.py → bcrypt + JWT + 依赖注入
  │
  ▼
Step 6  路由集成    main.py → 串联所有模块 + 中间件 + 错误处理
  │
  ▼
Step 7  测试数据    seed.py → 一键填充开发数据
  │
  ▼
Step 8  部署        Dockerfile → 容器化
```

## 文件依赖关系

```
database.py    ← 数据库连接
     ↓
models.py      ← 表结构定义（继承 database.Base）
     │
     ├─── schemas.py  ← 数据校验模型
     │
     ▼
crud.py        ← 数据库操作（依赖 models, auth）
     │
     ▼
auth.py        ← 认证（依赖 models, database）
     │
     ▼
main.py        ← 入口文件（依赖所有模块）
     │
     ▼
seed.py        ← 测试数据（依赖 models, auth, database）
```

## 路由层 vs 数据层

```
        HTTP 请求
            │
            ▼
   ┌────────────────┐
   │   main.py      │  参数解析、速率限制、权限检查、
   │  （路由层）     │  sanitize 过滤、响应格式
   └───────┬────────┘
           │
           ▼
   ┌────────────────┐
   │   crud.py      │  纯数据库读写
   │  （数据层）     │
   └───────┬────────┘
           │
           ▼
   ┌────────────────┐
   │  PostgreSQL    │
   └────────────────┘
```

- ✅ 统一错误格式
- ✅ Docker 容器化部署

## 推荐学习路径

1. **本地启动项目** — `uvicorn main:app --reload`
2. 打开 **Swagger 文档**（`http://localhost:8000/docs`）逐一测试每个 API
3. 修改代码后观察自动重载，理解每处改动的影响
4. 读完本教程后，尝试从零搭建一个类似的项目
5. 结合前端代码，理解全栈请求链路

> 整个后端约 770 行代码，实现了完整的论坛系统。这就是 FastAPI 的魅力——简洁、高效、安全。
