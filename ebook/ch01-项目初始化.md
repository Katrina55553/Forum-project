# 第一章：项目初始化 — 搭建骨架

## 技术选型

| 技术 | 用途 |
|------|------|
| **FastAPI** | Python 异步 Web 框架，自动生成 Swagger 文档 |
| **SQLAlchemy** | ORM（对象关系映射），用 Python 类操作数据库 |
| **PostgreSQL** | 数据库（开发时可用 Docker 启动） |
| **JWT** | 登录后的身份认证令牌 |
| **bcrypt** | 密码加密 |

## 项目目录结构

```
forum-project/
├── backend/
│   ├── venv/                    # Python 虚拟环境
│   ├── main.py                  # 入口文件（路由、中间件、错误处理）
│   ├── models.py                # 数据库模型（表结构定义）
│   ├── schemas.py               # 请求/响应数据格式（Pydantic 校验）
│   ├── crud.py                  # 数据库操作函数（纯数据层）
│   ├── auth.py                  # 认证逻辑（密码加密 + JWT 令牌）
│   ├── database.py              # 数据库连接配置
│   ├── seed.py                  # 测试数据填充脚本
│   ├── requirements.txt         # Python 依赖清单
│   ├── Dockerfile               # 容器化部署配置
│   └── migrations/              # 数据库变更记录
└── frontend/                    # Vue 3 前端（后续章节）
```

## 依赖说明（requirements.txt）

每一行对应一个明确的职责：

| 依赖 | 作用 |
|------|------|
| `fastapi` | Web 框架本身，处理路由、依赖注入、自动生成 OpenAPI 文档 |
| `uvicorn[standard]` | ASGI 服务器，负责运行 FastAPI 应用 |
| `sqlalchemy>=2.0` | ORM 框架，把 Python 类映射到数据库表 |
| `psycopg2-binary` | PostgreSQL 驱动，让 SQLAlchemy 能连接 PG |
| `bcrypt` | 密码哈希，比 SHA256 更适合存密码（慢 = 安全） |
| `python-jose[cryptography]` | JWT 令牌的生成和验证 |
| `slowapi` | 请求频率限制，防止暴力破解 |
| `bleach` | HTML 内容净化，防止 XSS 跨站脚本攻击 |
| `python-multipart` | 处理表单数据 |

## 后端文件依赖关系

```
database.py    ← 数据库连接配置
     ↓
models.py      ← 表结构定义（继承 database.Base）
     ↓
crud.py        ← 数据库操作（依赖 models, auth）
     ↓
auth.py        ← 认证逻辑（依赖 models, database）
     ↓
main.py        ← 入口文件（依赖所有模块）
     ↓
seed.py        ← 测试数据（依赖 models, auth, database）
```

## 本步骤核心要点

1. **职责分离**：每个文件只做一件事，按依赖关系从底层到上层组织
2. **配置外部化**：数据库地址、密钥等通过环境变量传入，不硬编码
3. **小即是美**：每个依赖只承担一个明确职责，不多也不少
