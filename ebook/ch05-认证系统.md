# 第五章：认证系统 — auth.py

认证系统是后端的**安全大门**，处理三个核心问题：

1. **密码加密** — 注册时存 bcrypt 哈希，不存明文
2. **JWT 签发** — 登录成功后颁发令牌（token），后续请求带着它证明身份
3. **身份解析** — 从 HTTP Header 取出 token，识别出当前用户

```python
import os
from datetime import datetime, timedelta, timezone
import bcrypt
from jose import JWTError, jwt

SECRET_KEY = os.environ.get("SECRET_KEY", "change-me-in-production-use-env-var")
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_HOURS = 24
```

> ⚠️ `SECRET_KEY` 必须通过环境变量设置，绝不能硬编码！当前默认值只是开发占位符。

## 密码加密

```python
def hash_password(password: str) -> str:
    return bcrypt.hashpw(password.encode(), bcrypt.gensalt()).decode()

def verify_password(plain_password: str, hashed_password: str) -> bool:
    return bcrypt.checkpw(plain_password.encode(), hashed_password.encode())
```

| 函数 | 做的事 | 场景 |
|------|--------|------|
| `hash_password` | 密码 → 加盐 → bcrypt 加密 → 存库 | 注册时 |
| `verify_password` | 明文密码 + 数据库 hash → 比对 | 登录时 |

**为什么用 bcrypt？** bcrypt 故意设计得很"慢"（消耗计算资源），而且内置盐值（salt），即使用户 A 和 B 密码相同，加密结果也不同。

## JWT 令牌

```python
def create_access_token(data: dict) -> str:
    to_encode = data.copy()
    expire = datetime.now(timezone.utc) + timedelta(hours=ACCESS_TOKEN_EXPIRE_HOURS)
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)
```

JWT 格式：`header.payload.signature`

解码后内容：
```json
{"sub": "1", "exp": 1717200000}
```

- `sub`（subject）— JWT 标准字段，存放用户 ID（转成字符串）
- `exp`（expiration）— 过期时间戳

**无状态认证**：服务器不存 token，全靠签名验证真伪，水平扩展不需要共享 session 存储。

## FastAPI 依赖注入 — 身份解析

### 必须登录

```python
security = HTTPBearer()

def get_current_user(
    credentials: HTTPAuthorizationCredentials = Depends(security),
    db: Session = Depends(get_db),
) -> User:
    payload = decode_token(credentials.credentials)
    if payload is None:
        raise HTTPException(status_code=401, detail="Invalid token")
    user = db.query(User).filter_by(id=int(payload.get("sub"))).first()
    if user is None:
        raise HTTPException(status_code=401, detail="User not found")
    return user
```

在路由中使用：
```python
@app.get("/api/auth/me")
def get_me(current_user: User = Depends(get_current_user)):
    return current_user   # 只允许登录用户访问
```

### 可选登录

```python
optional_security = HTTPBearer(auto_error=False)

def get_optional_user(...) -> User | None:
    if credentials is None:
        return None       # 没有 token → 返回 None，不报错
    ...
```

应用场景：帖子详情页。已登录能看到"取消点赞"，未登录看到"点赞"——同一个 API，用 `is_liked` 区分。

### 管理员检查

```python
def require_admin(current_user: User = Depends(get_current_user)) -> User:
    if not current_user.is_admin:
        raise HTTPException(status_code=403)
    return current_user
```

## 认证流程总结

```
注册 → bcrypt 加密密码 → 存入数据库

登录 → 查数据库 → verify_password 比对
     → 通过？生成 JWT（含 user_id + 过期时间）
     → 返回 token 给客户端

后续请求 → Header: Authorization: Bearer xxx
         → get_current_user 解码 JWT → 查数据库 → 返回 User 对象
```
