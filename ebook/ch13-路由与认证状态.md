## 导航守卫 — 认证拦截

```javascript
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem("token");
  if (to.meta.requiresAuth && !token) {
    next(`/login?redirect=${to.fullPath}`);   // 带来源页面
  } else {
    next();
  }
});
```

**工作流程：**

```
用户访问 /topic/new（需登录）
  → 检查 localStorage 有没有 token
  → 没有？→ 重定向到 /login?redirect=/topic/new
  → 用户登录成功后跳回 /topic/new
```

`redirect` 参数保证了用户体验——登录完成后直接回到原来想去的页面。

## 认证状态管理（stores/auth.js）

使用 Pinia 的 Composition API 风格：

```javascript
import { defineStore } from "pinia";
import { ref } from "vue";
import { login as apiLogin, register as apiRegister, getMe } from "../api/auth";

export const useAuthStore = defineStore("auth", () => {
  const user = ref(null);
  const token = ref(localStorage.getItem("token") || "");

  // 保存认证信息到内存 + localStorage
  function setAuth(t, u) {
    token.value = t;
    user.value = u;
    localStorage.setItem("token", t);
    localStorage.setItem("user", JSON.stringify(u));
  }

  // 清除认证信息
  function clearAuth() {
    token.value = "";
    user.value = null;
    localStorage.removeItem("token");
    localStorage.removeItem("user");
  }

  // 注册
  async function register(username, password) {
    const res = await apiRegister(username, password);
    return res.data;
  }

  // 登录：获取 token → 获取完整用户信息
  async function login(username, password) {
    const res = await apiLogin(username, password);
    setAuth(res.data.access_token, { username });
    await restoreUser();          // 获取带 id、is_admin 的完整信息
    return res.data;
  }

  // 从 token 恢复用户（页面刷新时用）
  async function restoreUser() {
    if (token.value) {
      try {
        const res = await getMe();
        user.value = res.data;
      } catch {
        clearAuth();              // token 失效 → 退出
      }
    }
  }

  function logout() {
    clearAuth();
  }

  return { user, token, register, login, restoreUser, logout };
});
```

### 为什么 login 要分两步？

```javascript
// 第一步：登录拿到 token
const res = await apiLogin(username, password);
setAuth(res.data.access_token, { username });   // 先存部分信息

// 第二步：调用 /api/auth/me 获取完整信息
await restoreUser();
```

登录接口只返回 `access_token`，不返回完整用户信息。所以拿到 token 后立刻调 `getMe()` 来获取用户完整信息（包括 `id`、`is_admin`、`avatar` 等）。

### 页面刷新后如何保持登录？

```javascript
// main.js 或 App.vue 启动时
const auth = useAuthStore();
auth.restoreUser();   // 从 localStorage 的 token 恢复用户
```

## 本章要点

- 路由守卫是前端的认证大门，检查 token 是否存在
- `?redirect=` 参数实现了登录后回跳
- Pinia 状态 + localStorage 双重持久化保证刷新不丢失登录
- login 两步走先拿 token、再取用户信息
