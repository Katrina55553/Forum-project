# 第十七章：评论与通知系统

## 递归评论组件 — CommentItem.vue

### 组件设计

CommentItem.vue 是前端最精妙的组件——它通过**递归渲染**实现无限层级的楼中楼。

```html
<template>
  <div class="comment" :style="{ marginLeft: depth * 20 + 'px' }">
    <!-- 评论头：作者、时间 -->
    <div class="comment-header">
      <span class="author">{{ comment.username }}</span>
      <span class="time">{{ formatTime(comment.created_at) }}</span>
    </div>

    <!-- 评论内容 -->
    <div class="comment-body">{{ comment.content }}</div>

    <!-- 操作按钮 -->
    <div class="comment-actions">
      <button v-if="auth" @click="showReplyForm = !showReplyForm">
        回复
      </button>
      <button v-if="canDelete" @click="handleDelete" class="danger">
        删除
      </button>
    </div>

    <!-- 内联回复表单 -->
    <form v-if="showReplyForm" @submit.prevent="submitReply" class="reply-form">
      <textarea v-model="replyContent" placeholder="写下你的回复..." rows="2"></textarea>
      <button type="submit">回复</button>
    </form>

    <!-- ⭐ 递归渲染子评论 -->
    <CommentItem
      v-for="reply in comment.replies"
      :key="reply.id"
      :comment="reply"
      :depth="depth + 1"
      :auth="auth"
      @reply="emitReply"
      @deleted="emitDeleted"
    />
  </div>
</template>
```

### Props

```javascript
const props = defineProps({
  comment: Object,     // 评论数据（含 replies 嵌套数组）
  depth: Number,       // 当前层级深度（顶层=0）
  auth: Object,        // 当前登录用户（null=未登录）
});
```

### 缩进逻辑

每条回复通过 `depth * 20px` 的左边距实现缩进：

```
depth=0  评论1
depth=1    ├── 回复1.1                ← marginLeft: 20px
depth=2    │   └── 回复1.1.1          ← marginLeft: 40px
depth=1    ├── 回复1.2                ← marginLeft: 20px
depth=1    └── 回复1.3                ← marginLeft: 20px
```

### 删除权限

```javascript
const canDelete = computed(() => {
  return props.auth && (
    props.auth.id === props.comment.user_id || props.auth.is_admin
  );
});
```

### 内联回复

点击"回复"按钮，在当前评论下方展开一个 textarea，不跳转页面：

```javascript
const showReplyForm = ref(false);
const replyContent = ref("");

async function submitReply() {
  if (!replyContent.value.trim()) return;
  await createComment(comment.topic_id, replyContent.value, comment.id); // parent_id=comment.id
  replyContent.value = "";
  showReplyForm.value = false;
  emit("reply");    // 通知父组件刷新评论列表
}
```

### 数据流

```
TopicDetailView.vue
  └─ CommentItem.vue (depth=0)
       └─ CommentItem.vue (depth=1)
            └─ CommentItem.vue (depth=2)
```

每个 CommentItem 通过 `@reply` 和 `@deleted` 事件向上冒泡，最终由 TopicDetailView 重新获取完整评论树。

## 通知页面 — NotificationsView.vue

### 通知列表

```javascript
const notifications = ref([]);
const loading = ref(true);
const page = ref(1);
const pages = ref(0);

async function fetchNotifications() {
  loading.value = true;
  try {
    const res = await getNotifications(page.value);
    notifications.value = res.data.items;
    pages.value = res.data.pages;
  } finally {
    loading.value = false;
  }
}
```

### 未读/已读样式

### 点击跳转 + 标记已读

```javascript
async function goToTopic(n) {
  router.push(`/topic/${n.topic_id}`);
  if (!n.is_read) {
    await markRead(n.id);       // 标记已读
    fetchUnreadCount();         // 刷新未读计数
  }
}
```

### 全部已读

```javascript
async function markAll() {
  await markAllRead();
  notifications.value.forEach((n) => (n.is_read = true));
  fetchUnreadCount();
}
```

### 导航栏通知徽章

<button class="notif-bell" @click="router.push('/notifications')">

```javascript
// 每 30 秒轮询
const unreadCount = ref(0);

async function fetchUnreadCount() {
  try {
    const res = await getUnreadCount();
    unreadCount.value = res.data.count;
  } catch {}
}

onMounted(() => {
  fetchUnreadCount();
  setInterval(fetchUnreadCount, 30000);
});
```

## 前后端对应总结

```
发评论：前端 createComment(topicId, content, parentId)
  → POST /api/comments { topic_id, content, parent_id }
  → 后端创建评论 + 原子更新用户评论数
  → 后端通知帖子作者（除非自回复）
  → 后端通知被回复的评论作者（除非已通知过）
  → 返回 CommentResponse

看通知：前端 getNotifications()
  → GET /api/notifications
  → 后端返回分页通知列表

标记已读：前端 markRead(id)
  → PUT /api/notifications/{id}/read
```

## 本章要点

- CommentItem 递归渲染实现无限层级楼中楼
- `depth` prop 控制缩进，`@reply/@deleted` 事件向上冒泡
- 内联回复表单不跳转页面，体验流畅
- 通知系统 30 秒轮询未读计数，导航栏显示小红点
- 点击通知 → 跳转帖子 → 标记已读，三个操作顺序执行
